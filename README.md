# Jira Service Desk Lab (Jira Service Management)

## Project Overview

This project demonstrates a simulated IT Support Service Desk environment using Jira Service Management. It focuses on practising common Level 1 IT Support tasks through incident management and service request workflows.

The lab covers practical troubleshooting, ticket prioritisation, ticket management, documentation and resolution tracking.

## Objectives

- Practise handling IT Support incidents and service requests.
- Investigate and troubleshoot common Windows and networking issues.
- Understand ticket prioritisation and status management.
- Document troubleshooting steps and resolutions.
- Gain hands-on experience with IT Service Desk workflows.

## Tools Used

- Jira Service Management
- Windows 11
- Windows Server 2022
- Oracle VirtualBox
- Cisco Packet Tracer
